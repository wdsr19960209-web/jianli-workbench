# jianli-workbench · 公路养护监理个人工作台

这是一个**从零搭的新骨架**，不是之前那个合并版的续改，也不含任何真实台账数据、账号和内网地址。

## 先说清楚的三件事

1. **已同步到聊天预览第二十四版的结构。** 五个页签：首页 · 工程概括、巡查统计、安全文件台账、病害台账、监理指令。监理问题那页已去掉。
2. **公开库红线：** 不要把 `.env`、`.db`、真实台账、内网系统地址、账号密码、通讯录电话、示意图原图提交进仓库。`.gitignore` 已经把 `.env`、数据库挡住了；通讯录和示意图只放在聊天预览里，不进这份代码。首页只写路段、桩号、里程、工区结构。
3. **不碰正在跑的东西：** 病害采集仍由你 Mac 上那套每 15 分钟的自动化负责，本骨架只做**只读展示**，不采集、不写月度表。

## 怎么跑

```bash
cd jianli-workbench
cp .env.example .env   # 按需改成本机路径，不提交
python3 run.py
```

打开 http://127.0.0.1:8080/ ，首页是工程概括，导航里有巡查统计、安全文件台账、病害台账、监理指令。

## 怎么接真实数据（Mac 本地版，数据不出本机）

只在你 Mac 本地跑时接真实数据，数据文件本身不进仓库、不上传：

```bash
# 在你 Mac 的工作台目录里建 .env（.env 已被 .gitignore 挡住，不会提交）：
SAFETY_LEDGER_CSV=~/Desktop/安全文件/安全文件台账.csv
DISEASE_LEDGER_DIR=~/Library/Application Support/disease-ledger
python3 run.py
```

- 安全台账：读本机 CSV 只读展示，登记和改状态仍在在线表里做。在线表是主表，工作台不改它；在线表和本机 CSV 目前是一致的（2026-11-04 核对过，都是第三期通报那 1 行）。
- 病害台账：优先读“病害处置台账_YYYY-MM.xlsx”，用纯标准库解析（`病害台账/disease_excel.py`，zip + xml，不装 openpyxl），没有 xlsx 时才回落到示例 CSV。采集那套 15 分钟脚本完全不动，工作台只读它写出来的月度表。
- 巡查统计：巡查页里“来自月度病害表”那一段，是按巡查记录编号去重算的，只含发现了病害的巡查，没发现病害的巡查不在表里，所以次数是下限，页上写明了这个口径。里程目前接不了实数（病害记录里没有里程字段），等智养巡查记录里里程字段名确认后再接。
- 巡查记录：第一次跑会在本机 `data/workbench.db` 建库（已进 `.gitignore`，不会提交），只存你自己在这页上新增的内容。
