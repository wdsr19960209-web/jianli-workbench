# jianli-workbench · 公路养护监理个人工作台（骨架版）

这是一个**从零搭的新骨架**，不是之前那个合并版的续改，也不含任何真实台账数据、账号和内网地址。

## 先说清楚的三件事

1. **只在本地看，不直接推 GitHub。** 本次交付就是这份本地骨架，你看过、改过、确认了再自己推。
2. **公开库红线：** 不要把 `.env`、`.db`、真实台账、内网系统地址、账号密码提交进仓库。`.gitignore` 已经把这些挡住了，真实数据只放在本机 `data/` 下（示例除外）。
3. **不碰正在跑的东西：** 病害采集仍由你 Mac 上那套每 15 分钟的自动化负责，本骨架只做**只读展示**，不采集、不写月度表。

## 目录：一个功能一个文件

```
jianli-workbench/
  run.py                  # 唯一启动入口，只绑 127.0.0.1，默认 8080
  安全/
    safety_read.py        # 只读：读本地安全台账 CSV
    safety_status.py      # 安全处理状态 -> 颜色（与在线表一致）
  工作台/
    render.py             # 公共页面、居中表格样式
    patrol_records.py     # 巡查记录：本地 SQLite 存取、按日期/关键词查
    issues.py             # 监理问题：本地 SQLite 存取
    reports.py            # 周报/月报：只做计数汇总，不编造内容
    instructions.py       # 监理指令：按既有模板套格式，不替你定责任
    knowledge.py          # 知识库：本地条目关键词搜索
  病害台账/
    disease_live.py       # 只读：读本地月度 CSV（示例格式，见 data/examples）
    disease_status.py     # 病害状态码 0/3/4/5 含义、颜色、当月隐藏规则
  data/
    examples/             # 示例数据（假数据，仅用来看页面长什么样）
```

## 怎么跑

```bash
cd jianli-workbench
cp .env.example .env   # 按需改成本机路径，不提交
python3 run.py
```

打开 http://127.0.0.1:8080/ ，首页有四个入口：安全文件台账、病害台账、巡查记录、监理问题。

## 怎么接真实数据（以后再做，不在这版里硬接）

- 安全台账：把 `.env` 里的 `SAFETY_LEDGER_CSV` 指到你本机那份台账 CSV，页面只读展示，登记和改状态仍在在线表里做。
- 病害台账：把 `DISEASE_LEDGER_DIR` 指到月度表所在文件夹，本骨架目前只认 CSV 示例格式；要读真实 Excel 时再单独加一个 `disease_excel.py`，不动采集那套。
- 巡查记录 / 监理问题：第一次跑会在本机 `data/workbench.db` 建库（已进 `.gitignore`，不会提交），只存你自己在这页上新增的内容。

## 这版故意没做的事

- 没有天气预警、没有 AI 记忆学习（你之前已明确排除老版那两项）。
- 没有自动去群里抓通知、没有平台采集、没有账号登录。
- 没有把老版、新版网站的数据库搬进来——旧巡查记录要不要迁、迁多少，先核对条数再定，不直接丢。
